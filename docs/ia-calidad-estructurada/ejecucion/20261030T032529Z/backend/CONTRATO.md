# Contrato de integración propuesto — paideia-education-v1

Configuración exclusivamente del servidor: `LocalChatService(..., structured_mode=True)` exige servicio habilitado, `test_only=True` y `provider.test_only is True`. El cliente no selecciona modo ni amplía la petición. Proveedor ficticio implementa `select_education(messages) -> dict`, una única llamada; respuesta cerrada `{version: 'paideia-education-v1', intent: 'explain'|'calculate', claim_ids: [IDs editoriales], scenario?: parámetros de calculate_scenario}`. Sin texto, refusal, extras, datos de resultado ni procedencia del proveedor. IDs editoriales previstos: `saving_investing`, `risk`, `inflation`, `guarantees`, `simulation`.

DTO de éxito: `{answer: texto editorial renderizado por servidor, provider_mode:'test_only', external_sent:false, structured_education:{version:'paideia-education-v1',kind:'editorial',items:[{id,text}],calculation:null|{source:'deterministic_local',data: resultado de domain.calculate_scenario ejecutado en este turno}}}`. `answer` concatena únicamente los textos de items, sin prosa de proveedor. La UI debe presentar items como contenido editorial y calculation como cálculo local; no interpretar answer como texto de proveedor. Contrato inválido: ServiceProblem 502 seguro sin fuga ni reintento. El cálculo requiere scenario validado y ejecución local; explain no acepta scenario. Consentimiento y privacidad originales preceden la llamada. Sin proveedor real ni modo por defecto.

Este documento anuncia el diseño para integración; consultar implementación y pruebas para detalles exactos de scenario y errores.

## Estado y aislamiento confirmados

`status()['capabilities']['structured_education']` es el booleano exacto: `true` solo con `structured_mode=True`; `false` en modo legado o no configurado. Si anuncia `true`, el frontend debe fallar cerrado cuando falte o sea inválido el DTO estructurado, sin fallback a prosa. El modo estructurado no admite context/history habilitados, tools habilitados ni admission; estas combinaciones fallan en configuración, no evaden la admisión. Se conserva la validación de consentimiento y rechazo de context/history antes de llamar.

El objeto `scenario` de `calculate` debe tener exactamente `principal`, `annual_rate_percent`, `years`, `monthly_contribution`, `method`, `inflation_percent`; years es entero no booleano, los demás strings decimales o método `simple`/`compound`, validados por `domain.calculate_scenario`. Ejemplo sintético: `{"principal":"1000","annual_rate_percent":"3","years":1,"monthly_contribution":"0","method":"simple","inflation_percent":"0"}`. `claim_ids` contiene entre uno y cinco IDs conocidos, sin repetidos. El error es `CHAT_STRUCTURED_INVALID_RESPONSE` (502); no se transmite detalle del proveedor.
