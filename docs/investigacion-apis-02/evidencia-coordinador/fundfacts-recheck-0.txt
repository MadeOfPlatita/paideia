## Frequently asked questions

An ISIN is the 12-character International Securities Identification Number that uniquely identifies a security, for example IE00B4L5Y983. FundFacts API supports UCITS funds, ETFs, money-market funds and most open-end funds that are covered by public fund data providers, worldwide.

Every response is built from the latest data the fund provider has published, so you always receive the freshest figures available for that fund.

From the fund's own published documents: the management company's product page, the monthly factsheet, the PRIIPs KID and, where the issuer publishes them, the holdings file and NAV history. We read those documents and normalise everything into a single JSON schema. Performance series and risk statistics are computed from the issuer's NAV history when one is published, and every payload carries the 'as of' date of the underlying figures.

The same sheets are on the site's SCPI pages.
