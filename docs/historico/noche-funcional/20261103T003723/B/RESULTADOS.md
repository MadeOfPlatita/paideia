# Hito B — informe de escenarios

Implementado y ejercitado con datos sintéticos y motor local real; pendiente de revisión independiente. No se usaron perfiles reales, proveedores externos, claves, instalaciones ni base de datos.

- `comparison_report.js` toma el snapshot público únicamente al imprimir, exige A/B actuales, contrasta supuestos normalizados, convenciones, moneda, integridad de serie y resúmenes; copia solo campos permitidos. Deshabilita y explica estados incompletos o errores. Cambio, navegación, impresión terminada y validación `beforeprint` invalidan el contenido anterior. No modifica funciones de estado de A.
- `comparison_report.css` separa impresión A4 del resto de la aplicación, repite cabeceras y ajusta cadenas largas. Diferencias B−A usan BigInt sobre céntimos ya serializados, no recomputan intereses. Se aclaran horizontes distintos, incertidumbre, aportación al final de mes, redondeo, impuestos y costes.
- `informe-sintetico.html` es copia autónoma utilizable; `informe-sintetico.pdf` fue generado realmente con Chromium CDP `Page.printToPDF` a partir de la pantalla preparada por el botón con `window.print` interceptado, no por una impresora física. Son supuestos ficticios: A simple, tasa −99 %, 40 años; B cero, 1 año. Fecha en UTC de generación, no de oferta. `pdf-texto.txt` es extracción PyMuPDF. 3 páginas A4; texto incluye mes 480, ambos escenarios, advertencias y diferencias; páginas inicial y final rasterizadas y revisadas visualmente con cabecera de tabla repetida y sin recorte observado.
- `extremo-sintetico.pdf`: 4 páginas para valor nominal de 51 dígitos enteros; PyMuPDF no encontró bloques de texto fuera de páginas y se observa mes 480. No se afirma evaluación visual exhaustiva de cada celda extrema.
- `desktop.json` y `mobile.json`: cada uno 18 comprobaciones correctas con motor local, incluidos edición, respuesta tardía, error, revalidación al clic y antes de imprimir, navegación, etiqueta maliciosa y marcador ficticio de perfil. Viewports 1440×900 y 390×844; clientWidth/scrollWidth 1425/1425 y 390/390. La prueba intercepta impresión para verificar el documento y retiene una respuesta HTTP real para probar la carrera; no sustituye cálculos.
- `race-extremo.json`: resultado real 452592596605447027503912597676958730429147429671389.28 conservado en salida, viewport móvil 390/390; captura whitelist y carrera de clic correctas. `node tests/report_unit.js` pasa: BigInt, cero negativo, importes grandes, estado mixto, supuestos y datos malformados. Ciclo RED inicial por módulo inexistente y RED posterior por rango no validado antes de implementar. Se reparó una prueba que inicialmente compartía una referencia mutable entre casos; se volvió a observar RED con el fixture aislado.
- Una primera ejecución móvil sin recarga limpia conservaba el estado anterior; se recargó explícitamente antes de los resultados finales. Una prueba preliminar en la sesión de navegador compartida fue interferida por otro trabajo; las pruebas finales usaron sesión aislada. No se ejecutó suite global ni se validó selección manual del diálogo de impresión/impresora; el PDF CDP sí existe y fue inspeccionado.

Reproducir: desde `app`, `node tests/report_unit.js`; iniciar servidor propio `python -u app.py --port 18765`, abrir `http://127.0.0.1:18765/#escenarios` en navegador aislado, ejecutar expresión de `tests/report_browser.js` y esperar resultado. Detener solo ese servidor. Las comprobaciones son sintéticas y no verifican seguridad frente a código arbitrario ejecutado dentro de la página ni exactitud independiente del motor financiero.
