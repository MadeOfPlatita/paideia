# Contrato provisional: contexto e historial

Solo pruebas sintéticas, no aprobado por A/B ni autorizado para perfiles reales o proveedores externos. `LocalChatService` tiene `context_enabled=False` y `history_enabled=False` por defecto; activarlos exige `test_only=True` y un proveedor marcado `test_only=True`. `/api/status` devuelve `ai.capabilities` con `context`, `history` y `synthetic_only`. El mensaje clásico `message` + consentimiento `paideia-chat-remote-v1` con `purpose=free_chat` y `approved_fields=[]` sigue siendo válido.

Extensión explícita de `/api/chat`: `context_consent={"notice_version":"paideia-chat-context-test-v1","context":true,"history":false}`; las dos banderas deben corresponder exactamente a la presencia de las claves respectivas. `context={"version":"chat-context-test-v1","fields":{...}}` admite únicamente `respuestas.objetivo`, `respuestas.horizonte`, `detalle_economico.importe_objetivo`, `detalle_economico.colchon_liquido`. Estados `sin_preguntar`, `no_se`, `omitido` no llevan valor; `declarado` lleva valor válido. Importes mantienen `min_eur` y `max_eur` como cadenas decimales y `moneda` EUR; cero no se convierte a desconocido. No se derivan clasificaciones. El cliente actual proyecta exclusivamente una muestra ficticia, no el perfil del usuario.

`history` contiene cero a cuatro mensajes alternos `user`, `assistant`, solo `role` y `content`, máximo dos turnos anteriores; roles privilegiados y metadatos de herramientas se rechazan. No se garantiza que el texto libre sea inmune a instrucciones maliciosas: el prompt lo trata como datos no confiables. La petición serializada tiene límite de 16 KiB UTF-8. El historial reside únicamente en memoria y tiene borrado explícito. Actualmente el modelo de interfaz puede conservar hasta tres turnos, aunque envía como máximo los últimos dos: pendiente ajustar ese límite de almacenamiento y su prueba preexistente.

Pruebas: `python -m unittest discover -s tests -p test_chat_context.py -v`; `node --test tests/chat_context_contract.test.cjs tests/chat_frontend_contract.test.cjs tests/chat_context_model.test.cjs`. El HTTP probado usa proveedor ficticio; no se ha realizado evaluación de modelo ni prueba de utilidad real.
